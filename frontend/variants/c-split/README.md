# Field Shift: variant C, "Split workspace"

A list-plus-map layout, like Airbnb, Zillow or Google Maps search results. Search and the farmer-priority filter pills sit in the top bar, a card list fills the left 44% of the screen, and a MapLibre map fills the right. The list and map stay in sync. All numbers are mock data, and a "Mock data" badge says so on screen.

## Run

```bash
npm install
npm run dev        # http://localhost:5173 (strictPort)
npm run mock       # regenerate src/mock/*.json from scripts/gen-mock.mjs
npm run build      # type-check + production build
```

Screenshots (with the dev server running):

```bash
cd ../../../design/tools && node shoot-c.mjs   # writes design/screenshots/c-0*.png
```

The script drives the real UI by clicking cards, scrolling the map with the mouse wheel to enter 3D, and clicking a cell. It waits for the map to go idle through `window.__map`.

## Flow

1. **Overview**: California map with listing-style pill markers and field cards. Hovering a card highlights its marker, and panning the map re-sorts the cards and marks any that are out of view. The muted "Why not BC yet" card sits at the bottom.
2. **Field**: opening a card turns the list into rotation listings (baseline + 3). Each listing has a 12-month strip, irrigation need vs allocation as a range, heavy-rain exposure, a score chip, tie badges and a Compare checkbox. The water-allocation stepper re-checks every listing. Priority pills re-weight the scores and re-sort the list (spec B4.12, tie when ranges overlap by more than 50%).
3. **3D drill-down**: scroll into the field past zoom 15. The camera pitches, the 30 m cells extrude, and the map switches to Esri imagery. The docked inspector has a layer picker (Cover/NDVI, Water use/ET, Heat stress), a legend, a 9 km SMAP vs 30 m size comparison and a click-a-cell readout. Scrolling back out leaves 3D.
4. **Your field's year**: weekly calendar 2016–2025 with risk ticks, green-up and harvest markers, the CDL crop for each year, numbered news markers, a rule vs ML detector toggle and outlines on weeks where the two detectors disagree.
5. **Compare**: the list widens to 69% for side-by-side columns. Each column shows irrigation need vs allocation, heavy-rain exposure, an OpenET check, score bars with whiskers and a baseline marker, insurance-loss chips, and Replay 2022 / 2023.
6. **Rotation brief**: an A4 print preview with source-numbered citation chips, the AI-check summary, a local-review checklist and a section picker. `window.print()` uses print CSS.

## Structure

```
src/
  api.ts            the only data access; mock today, B3 routes documented per function; scoring + tie rule
  types.ts          B3 shapes (SourcedNumber, Location, RotationStrategy, ...)
  measures.ts       3D layer colour ramps / heights
  MapView.tsx       MapLibre: OpenFreeMap streets, Esri imagery, field polygons, SMAP cell, extrusions
  App.tsx           state + split layout
  components/       TopBar, FieldCards, RotationList, YearView, CompareView, BriefView, Inspector, Bits
  mock/*.json       generated by scripts/gen-mock.mjs (deterministic)
```

Map sources follow CONTRACT.md, and no API keys are used. Real dates, events and URLs come from planner-spec.md. All other numbers are illustrative and marked `method: "assumed"`.
